# AI Watch v0.20.0

新增 Windows 展域水冷小屏幕串流，保留原有八个助手模块、三套皮肤、macOS 桌面功能和局域网多端同步。

### 新功能与修正

- **Windows 小屏幕串流**：在“配置 → 小屏幕串流”选择参数并开启，默认 2240 × 1080、30 FPS、8 Mbps。当前适配 `zhanyu` / TRYX PANORAMA PASE_1021；连接前退出占用设备的厂商程序。应用只向设备发送专用离屏页面，不采集整个桌面。
- **曲面布局**：左右分区，左侧四张 Agent 卡片自动翻页，右上显示原版看板娘与台词，右下显示近 24 小时真实额度历史。没有历史时显示“记录中”，不补造曲线或把余额当百分比。
- **等待提醒**：提问 / 授权时全屏显示对应角色和大号红字，多条任务每 6 秒轮播，处理后恢复监看；仍需在电脑上的对应助手中完成回答或授权。
- **后台输出与侧栏**：桌面可以折叠为侧栏、最小化或收纳，离屏输出继续运行；启动失败和停止后恢复桌面布局，恢复失败会显示错误。
- **完整 Windows 安装包**：内部 Python 桥、ARM64 设备端程序和从固定官方源码构建的 FFmpeg / x264 编码器随包提供，完整对应源码、构建脚本与许可证一同保留。辅助程序无需额外安装 Python 或 FFmpeg。

### 下载与升级

| 系统 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `AI-Watch-0.20.0-mac-arm64.dmg`，另附 `.zip` |
| macOS Intel | `AI-Watch-0.20.0-mac-x64.dmg`，另附 `.zip` |
| Windows x64 | `AI-Watch-0.20.0-win-x64.exe` |

升级前完全退出 AI Watch 并备份旧应用和完整用户数据，再替换或运行安装程序。偏好与自选图片沿用原配置。Windows 安装结束后手动启动。macOS 包保留原桌面功能，小屏幕 USB 桥当前仅用于 Windows。

同页 `SHA256SUMS.txt` 提供五个安装文件的 SHA-256。macOS 可使用 `shasum -a 256 <文件名>`，Windows PowerShell 可使用 `Get-FileHash <文件名> -Algorithm SHA256` 核对。

### 验证范围

- 发布前本地 macOS 完成 558 项 Node 单元测试、26 项 Python 单测、TypeScript / Vite 生产构建、24 组三套皮肤和 54 项曲面屏检查，以及桌面布局回归。小屏布局、只读 IPC、后台渲染、额度历史及 LAN 来源使用隔离配置和合成数据检查；Python 模拟设备测试覆盖启动、停止、取消和恢复失败。
- 发布工作流在 macOS ARM64 / Intel 原生 runner 分别构建 DMG / ZIP，检查签名完整性、DMG 和正式应用启动。
- Windows 原生 runner 构建完整串流桥，检查资源并进行真实 BGRA → H.264 编码，不连接 USB；打包后与 NSIS 安装后分别检查正式应用启动和桥接组件。
- 所有构建通过后创建草稿 Release，逐个核对上传大小和 SHA-256，再公开发布。确切来源提交与构建记录由工作流在文末附加。

### 已知限制

- **实体展域设备显示、画质、持续帧率、热负载及停止后厂商界面恢复尚待硬件验收**。目标 FPS 不代表实机 FPS；编码和预览测试不能替代 USB 硬件验证。
- Windows 各助手真实服务和完整窗口交互仍需实机验收；Linux 本次不发布。新硬件控制文案使用中文和英文回退。
- macOS 为 ad hoc 签名，未提供 Developer ID 签名和 Apple 公证；Windows 未 Authenticode 签名。首次运行可能遇到系统保护提示，请核对来源和摘要后按系统提示处理。
- 局域网同步为带配对令牌的明文 HTTP，请在可信网络使用。
- 普通安装包不含原生桌面小组件；沿用现有默认图标和较大 JavaScript chunk 提示。
