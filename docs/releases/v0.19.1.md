AI Watch **v0.19.1**，基于最新 `main` 的发布构建，取代 v0.19.0。本次构建的来源提交与 Actions 运行链接由发布工作流附在本文末尾。

### 本次变化

- **局域网多端同步**：在“配置 → 多端同步”中把一台设备设为主客户端、其他设备设为子客户端。子客户端通过配对码连接后，同步显示主客户端的状态、额度、待回答 / 待授权提醒、动态与趋势；外观和语言保留本机设置。默认关闭，只接受局域网地址，不共享登录凭据、密钥或本机路径。
- **Codex 提醒修复**：Codex 待回答 / 待授权在大型客户端状态下也能及时识别。
- **Claude 桌面 Code 提醒**：区分“待回答”（提问）和“待授权”（工具授权），处理后自动恢复；未开启辅助功能时也能显示。
- **Windows 安装包更精简**：修正打包配置，安装包只包含应用本身，不再带入仓库中的其他文件和 macOS 专用辅助程序。

### 下载与安装

| 系统 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `AI-Watch-0.19.1-mac-arm64.dmg`，另附 `.zip` |
| macOS Intel | `AI-Watch-0.19.1-mac-x64.dmg`，另附 `.zip` |
| Windows x64 | `AI-Watch-0.19.1-win-x64.exe` |

macOS 打开 DMG 后将 AI Watch 拖入 Applications，或解压 ZIP。Windows 运行 EXE 安装后手动启动。升级前完全退出旧应用并备份应用与用户数据，保留偏好及自选图片。

同页 `SHA256SUMS.txt` 提供五个安装文件的校验值。macOS 可运行 `shasum -a 256 <文件名>`，Windows PowerShell 可运行 `Get-FileHash <文件名> -Algorithm SHA256` 核对。

### 已知限制

- macOS 普通包使用 **ad hoc 签名，未提供 Developer ID 签名和 Apple 公证**；Windows 包 **未 Authenticode 签名**。首次运行可能遇到 Gatekeeper / SmartScreen 提示，请核对项目来源与文件摘要后按系统提示处理。
- 多端同步为局域网明文 HTTP（有配对令牌，未加密），请在可信网络中使用；首次作为主客户端时系统可能询问是否允许传入连接。
- Windows 上真实助手接入与完整窗口交互仍待更多实机验收；Linux 本次不发布。
- 普通安装包不包含原生桌面小组件。保留既有大 JavaScript chunk 提示和默认 Electron 应用图标。
